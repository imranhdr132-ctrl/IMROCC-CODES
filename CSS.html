CSS

Cascading Style Sheets

01 • INTRODUCTION

What is CSS?

CSS stands for Cascading Style Sheets. It is used to make HTML websites look beautiful. With CSS you can change colors, sizes, spacing, layouts, backgrounds and much more.

02 • CSS LESSONS

Learn CSS Codes

Start with these basic CSS lessons and practice each code.

01

CSS Selectors

Selectors tell CSS which HTML element you want to style. 

p {
    color: blue;
}
02

Colors

Change the text color using the color property. 

h1 {
    color: red;
}
03

Backgrounds

Add a background color to an element. 

body {
    background-color: lightblue;
}
04

Font Size

Use font-size to make text bigger or smaller. 

h1 {
    font-size: 50px;
}
05

Margin & Padding

Margin creates outside space and padding creates inside space. 

.box {
    margin: 20px;
    padding: 20px;
}
06

Borders

Add a border around an HTML element. 

.box {
    border: 2px solid blue;
}
