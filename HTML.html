HTML

HYPER TEXT MARKUP LANGUAGE

01 / INTRODUCTION

What is
HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

HTML uses tags to tell the browser what each part of a webpage means. 

<h1>My Website</h1>

<p>
    Welcome to my website.
</p>

02 / HTML LESSONS

Learn the
basics.

01
<h1>

Headings

Headings are used for titles and subtitles. HTML provides h1 to h6. 

<h1>Main Heading</h1>
<h2>Small Heading</h2>
02
<p>

Paragraphs

Use the paragraph tag to write normal text on your website. 

<p>
    Hello World!
</p>
03
<a>

Links

Links allow users to move from one page to another. 

<a href="page.html">
    Open Page
</a>
04
<img>

Images

The image tag lets you place pictures inside your website. 

<img src="photo.jpg"
alt="My Photo">
05
<ul>

Lists

Create ordered and unordered lists using HTML. 

<ul>
    <li>HTML</li>
    <li>CSS</li>
</ul>
06
<div>

Divisions

The div element is commonly used to group parts of a webpage. 

<div>
    <h2>Hello</h2>
</div>
