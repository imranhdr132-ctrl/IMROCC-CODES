10 HTML Tags Every Beginner Should Know

Learn the most important HTML tags and understand how they are used to create websites.

What Is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of a webpage. HTML tells the browser what different parts of a website are.

When you start learning web development, HTML is one of the first technologies you should learn.

01. Heading Tags

Heading tags are used for titles and headings. HTML provides headings from H1 to H6.

HTML
<h1>My Website</h1>
<h2>About Me</h2>
<h3>My Skills</h3>

02. Paragraph Tag

The paragraph tag is used to write normal text on a webpage.

HTML
<p>
Welcome to IMROCC CODES.
</p>

03. Link Tag

The anchor tag creates links that allow users to move between webpages.

HTML
<a href="Learn.html">
Learn HTML
</a>

04. Image Tag

The image tag is used to display pictures on a webpage.

HTML
<img src="image.jpg"
alt="My Image">

05. List Tags

Lists are useful when you want to show multiple items in an organized way.

HTML
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

06. Div Tag

The div tag is commonly used to group different parts of a webpage together.

HTML
<div>
    <h2>My Website</h2>
    <p>Welcome!</p>
</div>

Basic HTML Structure

Most HTML pages start with a basic structure like this:

HTML
<!DOCTYPE html>
<html>

<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>
        Welcome to my website.
    </p>

</body>

</html>
!

Beginner Tip

Don't try to memorize everything at once. Practice small pieces of HTML and build simple webpages.
